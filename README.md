# KARICHE coaching

French and Arabic website for Abdelkrim Kariche. Uses the supplied portrait and both original coach-training certificates: musculation and fitness, 50 hours each, from International Coaching & Development Group in Tlemcen. Certificate scans are rendered in landscape orientation for display, with the original PDF accessible in the image viewer. No accreditation claims, client results or testimonials are invented.

Prices were explicitly confirmed by the user: 25,000 DZD for one month, 45,000 DZD for two months, 60,000 DZD for three months.

Contact: WhatsApp +213 557 38 28 92; email Krimoukariche89@gmail.com. The local Algerian number supplied by the user was normalized to 213557382892 for WhatsApp.

Visitors choose a goal and coaching duration, fill a request, consent to share their details, then review their prepared message. WhatsApp and mail links open the visitor's application; the visitor sends the message there. The site does not automatically send, store enquiries or process payments. Payment terms are confirmed with the coach. Only the language preference is kept locally on the visitor's device.

Static public source and all assets are at the repository root; no dependencies or build command are required. Import the repository into Vercel using the Other preset and repository root. The supplied `vercel.json` selects static hosting. Both languages isolate numeric prices left-to-right to preserve Arabic ordering. Native dialogs support certificate enlargement and request review.
